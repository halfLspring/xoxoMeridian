# feat-082：默认小人自由拖拽与放置反馈

状态：已完成（2026-09-22），feat-082 已置 done。依赖 feat-080/081 已完成，用户已授权实施。

## 已确认行为

- 默认模型可在可见视口内自由移动，保留 12px 安全边距；不吸边、不惯性滑行，释放时页面位置固定。
- 当前浏览器跨刷新记住位置，不提供恢复默认的按钮、菜单或快捷键。生日主题保持原有布局和静态反馈。
- 移动端打开私聊时临时缩小并放在顶部，此时先关闭对话再移动；关闭后恢复保存的放置点。
- 使用现有 GLB 的整体程序化动作、HTML 符号与本地台词；不增加脸部或肢体资产。

## 实现约定

1. DOM 容器负责二维跟手，稳定 motion controller 负责 3D 姿态。Canvas、GLB 和聊天实例不因拖动重建；每帧更新使用 refs/rAF，不经 React 状态驱动整个对话。
2. 主指针移动超过 6px 才判定拖拽，保留抓取偏移。Pointer Capture 统一鼠标、触摸和笔。只抑制拖拽对应的兼容 click，下一次单击和 Enter/空格仍立即打开私聊。
3. 拖拽开始轻拎起约 0.10 模型单位，显示“↗ 诶，要带我去哪？”。拖动速度驱动小幅倾摆（水平约 ±0.12rad、纵向约 ±0.08rad）；停住收敛后停止多余 WebGL 帧。释放约 450ms 原地回稳并显示“✦ 好，就待在这里。”。减少动态偏好保留位置跟手和文字，关闭附加姿态动画。
4. 持久键 `xoxo:agent-entry:position:default:v1` 保存 `{version:1,x,y}`，x/y 为可放范围内的归一化坐标。它是当前浏览器的入口布局偏好，不带账号数据、不同步服务端。读取用同域 Zod schema 校验，浏览器在构造 schema 前关闭 Zod JIT 以兼容严格 CSP；异常或禁用存储时仍可操作，当前挂载期间保留位置。
5. 只有明确完成拖放或方向键移动才写入位置；临时展示、视口/软键盘变化、打开关闭弹窗、卸载都不写入。取消、丢失捕获、失焦、隐藏及移动中视口变化回到手势开始前位置，清理动作与指针。进入 `/chat` 再返回仍可从存储恢复。
6. 聚焦小人后方向键每次移动 10px，Shift+方向键 40px，松键提交；Escape 取消尚未提交的移动。Enter/空格保留开窗。为读屏提供移动说明，无重置功能。
7. 桌面面板按小人位置选择左/右更宽一侧，宽度适应剩余空间；小人仍能拖动，面板和气泡跟随布局。窄屏（可见宽度 <768px）开窗临时置顶且禁止移动；持久位置独立保存。气泡根据可见边界调整位置。
